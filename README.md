# Deloitte Australia Data Analytics Virtual Experience

## Project Overview
Completed a data analytics project as part of the Deloitte Australia virtual job simulation on Forage.

## Tools Used
- Tableau
- Microsoft Excel
- Data Visualization
- Data Analysis

- Create an interactive Tableau dashboard.
- Classify gender pay equality scores using Excel.

- Excel Formulas
